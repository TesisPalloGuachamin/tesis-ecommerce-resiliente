# Azure DRP Environment

This Terraform environment defines a designed Azure recovery target for DEVOPS-DRP-02.
It mirrors the current academic deployment model: one VM prepared for Docker Compose,
restricted ingress ports, and manual restore of compose assets and database backups.

This environment is intentionally not applied by default. It requires:

- Azure subscription and authenticated Terraform provider.
- VM quota for the selected `vm_size`.
- Valid SSH public key.
- Current operator CIDR.
- Database backup artifacts generated by the AWS DRP process.

Validation command:

```bash
terraform -chdir=infra/environments/azure-drp init -backend=false
terraform -chdir=infra/environments/azure-drp validate
```

Recovery remains designed until an Azure apply and restore drill is executed and measured.
